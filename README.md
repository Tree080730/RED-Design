# RED-Design · Food Passport Design System

React + TypeScript + Vite。品牌蓝 **#2563EB**，友好人物与贴纸表达；其他基础 tokens 直接继承 **antd 6.0.0**。

**新 Agent 接手：[START_HERE.md](START_HERE.md) → [HANDOFF.md](HANDOFF.md)。**

设计师手册：`/design-system#guide`。完整演示流程位于 `/demo`，并通过查询参数覆盖可吃、不能吃和未知三种结果。

```sh
npm ci
npm run dev
```

打开终端显示的地址；产品演示使用 `/demo`，规范站使用 `/design-system`。
