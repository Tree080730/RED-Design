# Character & Motion

## 资产与状态分离

预览和动作共用 Avatar，按部件组合。人物 v0.2 采用 240×280 半身像画布，嘴部约为 (121,173)，头部动画锚点约为 (120,130)。实际舞台食物动画按嘴部位置衔接。示例负向状态是倾斜与表情变化，不等于用户已确认最终“死翘翘”分镜。

## 动效来源

控件与布局转场直接使用 Ant Design motionDuration / motionEase。吃食物的叙事片段由 `motionDurationSlow × 4` 组合；JS 完成时间与 CSS 使用同一来源，不新增基础时间刻度。位移、旋转与缩放属于叙事关键帧的几何参数。

状态流：idle → eating → match/conflict。unknown 直接进入待确认；减少动态效果（系统或示例开关）直接展示结果。

## 中断与降级

嘴部配置预览、饮食设置大嘴、照片确认、checking 与结果态均以 `FinalMouthPortrait` / `MouthFrame` 为唯一基础几何。页面只提供不同的取景与展开终点；闭嘴线、口水、结果流体和泡沫作为动作层叠加，不重新绘制另一套鼻子、嘴框、牙齿或舌头。

产品拍照 → 照片确认：点击快门时记录取景区实际边界，照片表面用 820ms 连续移动、缩放到确认页照片槽位并形成圆角。落位后标题、人物、操作区按 100ms 间隔依次渐显（各 360ms）。转场期间暂禁操作，完成后恢复；减少动态直接展示最终页，窗口尺寸变化结束转场，卸载时取消动画。当前取景与照片均为黑色 Demo 占位；实际预览位于 `/demo` 拍照流程。

检查结果出现：分析中的 emoji 用 360ms 缩小淡出，最终 emoji 延迟 100ms 后用 560ms 柔和放大进入；结果标题延迟 280ms、详情入口延迟 400ms，各用 440ms 上移渐显。减少动态模式隐藏过渡帧并直接显示最终 emoji 与文字。

播放前取消旧计时，切换结果、工作台模式、重置或离开组件取消动作；重复点击不重复生成历史记录。切换减弱动态开关回到待机。系统 `prefers-reduced-motion` 禁止非必要 CSS 动画。

角色选择始终保留在当前沙盒中；最终结果与短标签持续可见。不自动播放语音，不用音效作为理解条件。

最终画风、负向动作的强度、未知动作、镜头衔接与资产数量，留给后续业务设计确认。
