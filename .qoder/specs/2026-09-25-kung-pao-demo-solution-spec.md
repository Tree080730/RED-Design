# 宫保鸡丁真实演示方案

## 已确认目标

- `/demo?result=cannot-eat` 以宫保鸡丁作为唯一菜品贯穿拍照、照片确认、分析结果与详情页。
- 使用真实菜品照片，不再使用黑色占位或沙拉 emoji。
- 演示用户因个人设置中的 `Peanut` 与 `Mild spice` 和宫保鸡丁中的花生、干辣椒发生冲突而得到 `Can’t Eat`，国籍不作为判断依据。
- 下方共享嘴、口水、咀嚼与不能吃流体状态保持现有实现。

## 复用与数据

- 新增 `demoFood.ts` 作为菜品名称、图片、说明、分析图标和命中标签的唯一来源。
- 真实图片资产：`public/kung-pao-chicken-demo.png`。
- `?result=cannot-eat` 预设 `Peanut` 与 `Mild spice`，其他 Demo 路径仍保持空选择起点。

## 验收标准

- 相机取景、确认照片、最终结果缩略图与详情缩略图显示同一张宫保鸡丁照片。
- 结果和详情只显示 `Peanut`、`Mild spice` 两项命中原因。
- 从相机进入嘴巴设置后，`Continue` 先退出相机页面，再通过既有大嘴转场进入饮食习惯设置，转场不得覆盖在相机画面上。
- 切换 `0.5×`、`1×`、`2×`、`5×` 时，相机取景框和下方拍照控制区的尺寸与位置保持不变；缩放仅作用于取景框内部被裁切的照片层。
- `Flash`、快门和 `Invert` 作为一组在取景框下方的白色控制区内垂直居中。
- 嘴部主预览及所有包含舌头的选项缩略图统一使用“口腔、舌头、牙齿”的 SVG 绘制顺序，舌头不得覆盖牙齿。
- 点击照片确认页的 `Again` 后，小照片先反向扩大到相机取景框的尺寸和位置；切换回相机后，顶栏、倍数栏和拍照控制区依次渐显。
- 页面无溢出，原有嘴部动作和转场测试继续通过。
