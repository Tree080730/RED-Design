# 浅色嘴部配置页方案

日期：2026-09-22
路径：B/E（修改现有业务页面 + 复用现有嘴部配置能力）
专项：组件库、动效、工程

## 目标

参考用户提供的浅色个人造型页面，重新设计当前已有的嘴部配置页。页面仍只配置鼻子、嘴巴、牙齿、舌头和口腔内部颜色，不新增人物发型、脸型、肤色、服装或眼镜配置。页面只做本地交互原型，不连接账号、服务端或真实素材服务。

## 页面结构

1. 顶部安全区：返回按钮、页面标题和当前步骤信息；保持产品现有英文短文案。
2. 嘴部舞台：浅色页面背景，展示当前嘴部的大尺寸 SVG 预览；不引入完整人物 Avatar。
3. 分类切换：横向可滚动的 Nose、Mouth、Teeth、Tongue、Inside 分类；不使用参考图的深色底栏。
4. 当前分类的选项区：浅色卡片、蓝色选中描边/底色、最小 44px 点击区域；颜色选项使用圆形色板。
5. 底部操作：主按钮 Continue，点击后进入现有饮食条件页；返回操作回到上一步。

## 复用与改动范围

- 复用 `src/components/MouthConfig.tsx` 的 `MouthConfig`、预览 SVG 和部件渲染器。
- 修改 `src/pages/MouthSetup.tsx` 与 `src/pages/mouth-setup.css`，不新增人物 Avatar 页面。
- 保留 `DietPreferences` 当前流程：嘴部配置页 → 饮食条件页；返回操作逐层返回，不使用浏览器历史作为业务状态。
- 使已保存的嘴部配置被 `MouthFrame`、`JourneyMouth` 和结果状态共同读取。
- 仅在业务 Demo 中接入；规范站的 `CharacterLab` 保持原有沙盒行为。

## 视觉约束

- 画布基准 402×874；顶部和底部安全区各 44px。
- 使用白色页面底、`--ds-colorPrimaryBg` 浅蓝舞台和 `--ds-colorPrimary` 品牌蓝。
- 基础字号、间距、圆角、控件高度、动效时间全部引用 `--ds-*` 或 Ant Design 组件；不新增手写刻度。
- 卡片和标签使用现有 Token 圆角，参考图的深色背景、深色导航栏和大面积阴影不迁移到浅色版本。
- 人物 SVG 的肤色、发色、服装色等属于插画资产色，可继续来自 `avatarColors`。

## 交互与状态

- 修改选项即时更新预览，但只有点击 Save & continue 才提交到会话配置。
- Cancel 丢弃当前草稿并返回上一步；返回后不会覆盖已保存人物。
- 选择分类不会清空其他分类。
- 小屏分类区横向滚动，页面主体不产生横向溢出。
- 支持键盘焦点、`aria-selected`/`aria-pressed`、44px 触控区域和减少动态效果。
- 刷新是否保留人物配置暂定为“不保留”，与当前 Demo 的内存状态策略一致；若需要跨刷新保存，另行确认 localStorage 范围。

## 动效方案

- 分类切换只做轻量内容淡入，使用现有 Ant Design motion token。
- 保存时嘴部舞台保持稳定，按钮进入 loading/完成态后切换到下一页；不使用参考图中的深色沉浸式切换。
- 后续吃食动画继续使用同一份已保存嘴部配置，避免配置页与结果页嘴部不一致。

## 验收标准

- 402×874 下首屏无关键内容被遮挡，默认状态无需滚动即可看到预览、分类和保存操作。
- 分类切换、选项选择、取消、保存并进入 MouthSetup 可操作。
- 保存的 AvatarConfig 在嘴部页、拍摄页、checking、能吃/不能吃结果页保持一致。
- 360、390、402、430px 宽度无横向溢出。
- `npm run build`、`npm run typecheck`、`npm run check:tokens`、`npm run check:contrast` 和 Playwright 回归测试通过。
- 新增页面和状态在 `docs/delivery/` 记录，规范站不新增与业务页面重复的假控件。
