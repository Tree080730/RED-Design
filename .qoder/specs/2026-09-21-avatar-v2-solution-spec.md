# 人物 v0.2 迭代

状态：用户要求参考指定 Avatar Creator 迭代，按此明确方向实施。范围为现有 Design System 人物与编辑体验，不引入新业务流程。

## 问题与变化

现有小人是全身比例、点状眼睛、两个发型的占位插画。迭代为头像／半身像主导、几何色块、白眼与瞳孔、独立眉毛和嘴部、大预览 + 分类部件缩略图。

参考：https://blog.duolingo.com/avatar-creator/ 。参考组合机制和角色表达，不复制指定人物资产。原文可访问，配图在当前浏览器未加载成功。

## 范围

B/C/D + 动效/文档。重构 Avatar 部件；扩充脸型、发型、发色、肤色、上衣、眼镜与背景；单独切换外观编辑和反应预览。同一渲染器用于 hero、缩略图和动作舞台；编辑器保存的配置用于反应预览。Hero 仍是独立展示样例。预设角色支持一键试穿，非随机覆盖已保存用户档案。

## 约束

保持 antd6.0.0 全局与非颜色 token 不变。部件坐标和形状属于插画几何。无新依赖。现有反应类型和减少动态能力保留，最终负向分镜仍待后续确认。

## 验收

保存／取消可回退人物配置；不同分类选择共存；头像与反应是同一人物；所有开放发型、脸型和眼镜组合可见不裁切；窄屏没有页面溢出；类型检查、token 与配色检查、浏览器交互回归通过。
