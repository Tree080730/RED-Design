# Food Passport Design System｜已确认实施方案

状态：用户已指定方向并授权构建。替代此前暖白橙色方案。

## 确认依据

“请参考多邻国的设计风格和颜色体系来构建整个 design system，然后其他 design tokens 的内容直接复用 antd 6.0。”

## 分层

- 品牌：Duolingo 官方色板，白底、鲜明色块、角色主导、轻量活泼的视觉表达。
- 基础：安装并锁定 antd 6.0.0。非颜色 tokens 直接继承 defaultAlgorithm，不覆盖字号、字体、圆角、间距、控件高度、阴影或动效时长。
- 组件：优先实际使用 Ant Design Button、Tabs、Checkbox、Radio、Input、Switch、Modal；人物、食物和场景舞台作为组合组件。
- 样式冲突处理：不为了模仿多邻国而重设圆角或字体。卡通感主要来自配色、原创插画与布局。色彩对比不足的品牌色不用于小字，按钮使用深色文字。
- 动画只做可重用的示意状态，不锁定业务最终负向与未知表演；动画几何和关键帧不是基础设计 token。

## 范围与路径

F（A tokens + C 组件 + D 展示页），专项为工程、动效、文档。建立 React / TypeScript / Vite 项目、theme.ts、token bridge、规范文档和 /design-system 展示入口。此前无代码可复用。PRD 业务范围不扩展。

## 候选与复用

基础控件确认复用 antd；人物形象、部件数量和食物画风仍为示意，不视为最终设计确认。新增可组合 Avatar、FoodSticker、ReactionStage、ReasonChip，分别只负责外观、资产和状态表现，不内置真实判断。

## 交付

可运行规范站：总览、色彩、字体、基础 tokens、控件、人物／动效、约束。文档记录官方参考、覆盖白名单、继承清单、使用规则、启动和检查方式。写入 Project Adapter 作为本次已授权新项目的规范落盘。

## 验收

锁定版本、非颜色 token 与 antd 原值一致；构建与类型检查；实际交互验证；窄屏无横向溢出；角色配置贯穿不同状态；键盘／减少动态效果；组件与展示页共享同源 token。自动化检查只覆盖真实约束与交互，不为静态文字编写测试。

## 风险与边界

品牌绿不能等同于“过敏安全”；保留原因标签和待确认语义。字体直接沿用 antd，不使用多邻国专有字体。示意角色原创，不使用 Duo 吉祥物。UI 开放的新部件需兼容全部动作。外观和语义仍按 PRD 逐页确认。

## 本轮增量

用户明确新增 antd 依赖并替代颜色来源；按最新指示执行，不沿用此前不引入 UI 库的假设。React/Vite 构建依赖和自动化验证工具随项目落盘并记录。
