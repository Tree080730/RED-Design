# 首页可动头部

用户提供脸部参考图，明确要求加入首页上方、补头发、不要身体、不可直接贴图。

实现：`src/components/WelcomeHead.tsx` 与 `welcome-head.css`。脸部、双耳、白眼、瞳孔/高光、鼻子、嘴和头发均为独立 SVG 几何。保留浅桃肤色、紫褐瞳孔、小椭圆鼻、深红宽大开口嘴；补深棕短发。此人物只用于选择首页，未替换原有 Avatar 编辑器或改动确认页。

默认表情保持参考图；轻微浮动与周期眨眼，鼠标跟随瞳孔，点击摇头。头发沿头皮轮廓包覆，发际线连续延伸至两侧鬓角；取消独立旋转，使头发与头部同步运动，避免发根脱离。遵循系统减少动态效果。SVG 部件可进一步接入吃与反应动画，本轮未实现进食动作。艺术几何/颜色属已有插画资产边界，不新增 UI token。

预览：/demo。画布 402×874，截图 diet-welcome-head.png。新增头部后沿用现有界面间距；同时修复键盘显现时依据整块输入框边界滚动，避免只照顾文字输入区域而遮挡外边缘。
